# Мяфграм

Мяфграм — независимая пользовательская сборка на основе Telegram Web K.

## Разработка

Требуются Node.js 22.18+ и pnpm 11.

```bash
pnpm install
pnpm start
```

Для production-сборки:

```bash
pnpm build
```

## Конфигурация

Для подключения к Telegram укажи собственные параметры API в локальном окружении сборки согласно конфигурации Vite проекта. Не добавляй API hash, токены ботов или другие секреты в Git, публичные issue и сообщения.

## Android

Проект сохраняет PWA-манифест. Установка на Android через браузер будет доступна после публикации production-сборки по HTTPS. Отдельный APK и его подпись пока не настроены.

## Функции

Дополнительные функции (Ghost mode, локальный архив удалённых сообщений и менеджер ботов) находятся в планах и не должны считаться реализованными до появления соответствующего кода и тестов.
