# Мяфграм — нативная Android-ветка

Эта ветка готовит отдельную нативную сборку на основе официального исходного кода Telegram for Android: https://github.com/DrKLO/Telegram

## Важно

- Это не Telegram Web и не WebView-обёртка.
- Приложение неофициальное и не связано с Telegram.
- Исходный код Telegram распространяется по GNU GPL v2 или более поздней версии. Перед распространением APK нужно публиковать соответствующий исходный код и изменения, сохранять уведомления об авторских правах и выполнять условия лицензии.
- Не используйте название или стандартную иконку Telegram так, чтобы приложение выглядело официальным.
- Ветка `main` со старым веб-проектом не изменяется.

## Подготовка API

Для собственной сторонней сборки Telegram требует отдельные API ID и API hash:
https://core.telegram.org/api/obtaining_api_id

Не отправляйте API hash, коды входа, пароли или токены в чат и не коммитьте их в Git.

В настройках GitHub репозитория добавьте **Repository variables**:

- `MYAFGRAM_API_ID` — числовой API ID.
- `MYAFGRAM_API_HASH` — API hash.

Workflow завершится с понятной ошибкой, если эти переменные не заданы.

## Сборка

1. Откройте Actions в репозитории.
2. Выберите **Build Myafgram Native Android**.
3. Нажмите **Run workflow** и выберите ветку `native-android`.
4. После завершения откройте artifact `myafgram-native-android-debug`.

Сборка использует Java 17, Android SDK 36, NDK 27.2.12479018 и CMake 3.22.1, как требует текущая upstream-версия проекта.

## Ограничения первой сборки

- Это первая техническая сборка; запуск на устройстве ещё не подтверждён.
- В workflow используется временная конфигурация Firebase только для прохождения конфигурации Gradle. Push-уведомления не будут считаться настроенными; для релиза нужен собственный Firebase-проект и корректный `google-services.json`.
- Подпись debug APK предназначена для тестирования, не для публикации в магазине.
- Перед распространением необходимо проверить все upstream-требования и лицензии зависимостей.
